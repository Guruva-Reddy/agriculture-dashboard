#  Agriculture Crop Production Analysis Dashboard

#  Project Overview

This project is an interactive Power BI dashboard developed to analyze crop production data across different states and districts in India. The dashboard helps users explore agricultural production trends, crop-wise performance, seasonal production, and yield analysis through dynamic visualizations.

The dashboard is designed to assist farmers, researchers, policymakers, and agricultural organizations in making data-driven decisions.

---

#  Objectives

- Analyze crop production across different states and districts.
- Compare crop yield and cultivated area.
- Identify top-performing crops and regions.
- Monitor production trends over multiple years.
- Support data-driven agricultural planning.

---

#  Dashboard Features

-  KPI Cards
  - Average Yield
  - Total Area
  - Total Production
  - Total Crops
  - Total States
  - Total Districts

-  Interactive Filters
  - State
  - District
  - Crop
  - Season
  - Year

- Visualizations
  - Top Producing States
  - Top Crop Production
  - Crop Production Trend
  - Production by Season
  - District-wise Production
  - Area vs Production Analysis
  - Average Yield by Crop

# Business Insights

- Kerala recorded the highest crop production.
- Coconut is the highest-producing crop.
- Production trends vary across years and seasons.
- Area under cultivation significantly impacts crop production.
- Interactive filters enable detailed analysis by state, crop, and season.
